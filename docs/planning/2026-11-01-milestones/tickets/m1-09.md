## Acceptance criteria

- [ ] **Given** required explanation 1 or 2, **when** back/outside/drag is attempted, **then** it is not bypassed before the approved required-permission action.
- [ ] **Given** optional recommendation, **when** close/back is used, **then** foreground Home remains available.
- [ ] **Given** widths 839 and 840 dp, **when** each prompt is shown, **then** presentation changes from bottom sheet to centered dimmed dialog with identical permission logic.
