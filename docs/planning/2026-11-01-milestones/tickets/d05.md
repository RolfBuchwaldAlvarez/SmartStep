## Acceptance criteria

- [ ] **Given** the PDF permits a real public free-tier LLM API and recommends Gemini, **when** accepted, **then** the selected provider/model and credential architecture are recorded with owner authorization for any infrastructure/cost.
- [ ] **Given** fixed insight context, **when** accepted, **then** exactly which structured data leaves the device and how chat history is handled are stated; no extra profile data is assumed necessary.
- [ ] **Given** offline, timeout, HTTP error, quota exhaustion or a cancelled screen, **when** accepted, **then** each state has a defined retry/error outcome and no simulated insight is presented as real AI.
