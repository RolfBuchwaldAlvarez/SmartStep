## Acceptance criteria

- [ ] **Given** nonblank user input, **when** sent, **then** append it immediately and append the AI response in chronological order on arrival.
- [ ] **Given** a fixed quick-suggestion prompt, **when** dispatched, **then** use the same sending path and add it as a user message.
- [ ] **Given** blank, concurrent, cancelled or failed sends, **when** processed, **then** use D05/D06 behavior without stale responses leaking into a later session.

## In scope

Trim/nonblank validation, ordered message list, in-session context and bounded error/retry/send policy.

## Out of scope
