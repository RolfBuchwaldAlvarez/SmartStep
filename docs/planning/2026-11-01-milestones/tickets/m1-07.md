## Acceptance criteria

- [ ] **Given** first Home display with no activity access, **when** eligible, **then** request through the real system dialog once rather than a custom imitation.
- [ ] **Given** first/second denial, settings grant or ungranted relaunch, **when** state refreshes, **then** the corresponding explanation/re-prompt/settings state follows D02 and SS-M1-13.
- [ ] **Given** recreation or repeated resume events, **when** callbacks arrive, **then** no overlapping system launches occur and required access is never falsely reported granted.

## In scope

Single request mechanism, durable relevant request history, real system prompts and settings-return refresh.

## Out of scope

Sensor counting or battery-access recommendation.
