## Acceptance criteria

- [ ] **Given** a fresh install with no completion record, **when** launch resolves storage, **then** profile setup appears after splash.
- [ ] **Given** Start or Skip was successfully persisted, **when** the process is relaunched, **then** Home opens without briefly showing setup.
- [ ] **Given** loading or a read failure, **when** routing resolves, **then** no second profile save or accidental completion occurs; retry behavior is documented.

## In scope

Read persisted completion/profile before deciding the initial route; explicit loading/error result; reuse Room.

## Out of scope
