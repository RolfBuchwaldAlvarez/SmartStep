## Acceptance criteria

- [ ] **Given** required activity access and foreground lifecycle, **when** sensor data arrives, **then** it reaches the reducer and observable Home count/progress.
- [ ] **Given** permission revoked, lifecycle stopped or absent sensor, **when** state changes, **then** registration/counting follow D02 without duplicate listeners.
- [ ] **Given** no background access, **when** UI leaves foreground, **then** no background service is started.
