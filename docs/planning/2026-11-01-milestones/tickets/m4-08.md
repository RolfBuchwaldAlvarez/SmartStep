## Acceptance criteria

- [ ] **Given** Home, **when** shown, **then** Report sits right/top-aligned with the primary step number and has no independent interactive state.
- [ ] **Given** background-card vs edit/pause taps, **when** used, **then** only noninteractive card regions open Report; existing controls do not accidentally navigate.
- [ ] **Given** Back and reopen, **when** navigated, **then** remove old report state and initialize under D07.

## In scope

Report label placement, typed route, centered Report/back bar and state disposal on Back.

## Out of scope

Making the informational label its own button or changing existing control semantics.
