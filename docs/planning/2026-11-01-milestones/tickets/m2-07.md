## Acceptance criteria

- [ ] **Given** Reset Today, **when** selected, **then** ask Are you sure you want to reset today’s steps? with Cancel/Reset.
- [ ] **Given** Cancel, **when** used, **then** data is unchanged; given confirmed Reset, then baseline moves to current sensor and today displays zero.
- [ ] **Given** later readings, **when** applied, **then** only new steps are added and historical days remain intact.
