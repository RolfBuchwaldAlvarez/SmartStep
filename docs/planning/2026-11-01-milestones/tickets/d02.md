## Acceptance criteria

- [ ] **Given** minSdk 29/targetSdk 36 in the audited app, **when** platform documentation and device behavior are checked, **then** first denial, permanent denial, settings return and relaunch have explicit expected outcomes.
- [ ] **Given** background access is optional, **when** the owner chooses the flow, **then** dismiss/decline allows foreground use and unsupported exemption/sensor cases have defined user behavior.
- [ ] **Given** Exit requires no autonomous restart, **when** accepted, **then** the supported stop/suppression mechanism, notification-permission denial and resumption on explicit relaunch are documented without equating battery exemption with every Android permission.

## In scope

Runtime activity access, denial/settings states, optional battery exemption, absent sensor, notification denial and explicit user exit.

## Out of scope

Implementing tracking or promising the OS can terminate every process universally.
