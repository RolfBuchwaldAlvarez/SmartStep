## Acceptance criteria

- [ ] **Given** first-session/foreground/goal-reached/goal-change events, **when** eligible and Home active, **then** refresh according to D06 once per event policy.
- [ ] **Given** minor step changes or no triggering event, **when** data updates, **then** reuse the insight and make no periodic request.
- [ ] **Given** a request, **when** built, **then** include steps/goal/completion/time context only and ask for independent concise nonmedical output under the approved numeric rule.
