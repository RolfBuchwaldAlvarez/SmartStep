## Acceptance criteria

- [ ] **Given** today, **when** queried, **then** return exactly today and previous six calendar dates with today last.
- [ ] **Given** missing/zero activity days, **when** averaging, **then** include all seven days in the denominator.
- [ ] **Given** later goal changes or midnight, **when** queried again, **then** historical goal progress stays unchanged and the date window advances.
