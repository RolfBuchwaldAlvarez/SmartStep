## Acceptance criteria

- [ ] **Given** online/offline transitions, **when** callbacks arrive, **then** observers update without navigation or screen refresh.
- [ ] **Given** observer disposal/recreation, **when** lifecycle changes, **then** callbacks are cleaned up and initial state is refreshed.
- [ ] **Given** connectivity online but an API failure, **when** observed, **then** the transport error remains distinct from offline state.

## In scope

Lifecycle-safe connectivity boundary and observable state shared by AI features.

## Out of scope

Treating network availability as proof the provider request will succeed.
