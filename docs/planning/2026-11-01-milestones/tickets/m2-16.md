## Acceptance criteria

- [ ] **Given** tracking while UI is closed, **when** data changes, **then** steps/calories update silently and reopening Home observes the same ledger.
- [ ] **Given** Pause/Resume or revoked access, **when** state changes, **then** service recording and displayed/frozen metrics follow the approved shared policy.
- [ ] **Given** notification dismissal and later new data, **when** eligible, **then** behavior matches D02 without generating attention-grabbing duplicate notifications.

## In scope
