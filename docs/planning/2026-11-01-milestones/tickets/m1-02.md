## Acceptance criteria

- [ ] **Given** selected profile values, **when** Start is tapped, **then** navigation occurs only after a successful save with those values.
- [ ] **Given** Skip, **when** save succeeds, **then** approved defaults are stored and onboarding is completed; a save failure leaves the user on setup.
- [ ] **Given** a suspended fake save or rapid repeated taps, **when** the UI remains active, **then** no premature Home event or duplicate write occurs.

## In scope

Await existing save use case, expose completion event/loading/failure and suppress duplicate submissions.

## Out of scope

Picker redesign or generic repository rewrite.
