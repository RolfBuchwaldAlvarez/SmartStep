## Acceptance criteria

- [ ] **Given** existing profile and M1-11 goal storage, **when** upgraded, **then** profile and the saved goal remain intact, the saved goal seeds today’s goal snapshot, and empty daily activity is distinct from recorded zero.
- [ ] **Given** day-scoped updates, **when** reloaded, **then** count/baseline/offset/duration/goal are coherent for the same date.
- [ ] **Given** a new goal today, **when** saved, **then** today/future use it while past day goals remain unchanged.

- [ ] **Given** D07’s approved historical-profile policy, **when** a profile change or later step edit is persisted and reloaded, **then** the ledger retains the inputs or computed metrics required to reproduce the approved past-day and same-day examples.

## In scope

Room entity/DAO/repository with date, displayed steps, sensor baseline/offset, duration, historical goal and D07-approved historical metric data; migration from profile and M1-11 goal storage. Keep M1-11’s repository as the single source of the current goal; snapshot it when creating a day record. Goal saves update that source and today’s snapshot coherently, leave past snapshots unchanged and initialize future days from the current goal. Do not introduce a second editable current-goal source.

## Out of scope

Sensors, report UI or speculative multi-module migration.
